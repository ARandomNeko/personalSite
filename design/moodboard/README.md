# Paint & phosphor

The current board at `/moodboard` studies the balance between historical paint and early computer structure: dark document panes, compact navigation, four-tone dither dissolving into visible brushwork, and native scroll-driven background changes.

The user's feedback explicitly steered the first browser demo away from a soft art-book treatment and back toward esoteric computer character. The new references are Turner, Böcklin, John Martin, and the supplied Monet sunset. Artist/source links are on every painting in the board; new image credits are in `static/paintings/README.md`.

`previous.html` preserves the earlier approved moodboard. Its assets include the supplied Moreau *Apparition* reference (not used in the demo), Delville's *Angel of Splendour*, and Monet's *Japanese Footbridge*.
